# Lire un panneau breton

La plupart des noms de communes de Bretagne se construisent avec un petit nombre de briques. Une fois ces trente repérées, un panneau cesse d'être une suite de syllabes : il se lit comme une phrase. « Plougastel », c'est la paroisse du château. « Locronan », le lieu consacré de Ronan.

Deux règles de lecture avant de commencer :

- L'orthographe varie. Un même élément s'écrit Plou-, Plo-, Plu- ou Plé- selon l'endroit et l'époque. On donne à chaque fois la racine et ses formes courantes.
- Quand une étymologie fait débat, c'est écrit. Ce site préfère « probablement » à une certitude inventée.

La forme bretonne du nom est donnée entre parenthèses quand elle est officielle.

## En tête de nom

**Plou- (Plo-, Plu-, Plé-, Pleu-)**
Paroisse, au sens de « paroisse primitive » (du latin *plebs*).
Exemples : Plougastel-Daoulas (Plougastell-Daoulaz), Plouhinec, Ploërmel (Ploermael).

**Ker-**
Village, hameau, lieu habité (du breton *kêr*).
Exemples : Kergrist, Kerlouan, Kersaint-Plabennec.
Attention : Quimper ne commence pas par Ker-. Sa forme bretonne, Kemper, vient d'un autre mot (voir plus bas).

**Lan-**
Ermitage, terre consacrée (du breton *lann*).
Exemples : Lannion (Lannuon), Landivisiau (Landivizio), Lanester (Lannarstêr).

**Tre-**
Trève, ancienne subdivision de paroisse (du breton *trev*).
Exemples : Trégastel (Tregastell), Trébeurden (Trebeurden), Trégunc (Tregon).

**Loc- / Lok-**
Lieu consacré, ermitage (du breton *lok*).
Exemples : Locronan (Lokorn), Locmaria (Lokmaria), Locminé (Logunec'h).

**Gwik- / Gui-**
Bourg (du breton *gwik*, lui-même du latin *vicus*).
Exemples : Guipavas (Gwipavaz), Guissény (Gwiseni), Guimiliau (Gwimilio).

**Gwen- / Gueng-**
Blanc (du breton *gwenn*) ; dans les noms de lieux, souvent entendu comme « béni, saint ».
Exemples : Guingamp (Gwengamp, « le champ blanc »), Guérande (Gwenrann, « le pays blanc »).

**Sant- / Saint-**
Saint.
Exemples : Saint-Brieuc (Sant-Brieg), Saint-Malo (Sant-Maloù), Saint-Pol-de-Léon (Kastell-Paol).

**Pen- / Penn-**
Tête, bout, pointe (du breton *penn*).
Exemples : Penmarc'h, Pencran (Penn-ar-C'hraon).

**Ros-**
Tertre, colline (du breton *roz* ; sens probable, le mot a évolué).
Exemples : Roscoff (Rosko), Rosporden, Rostrenen (Rostrenenn).

**Poull- / Poul-**
Mare, anse, creux d'eau (du breton *poull*).
Exemples : Pouldreuzic, Pouldergat, Le Pouldu.

**Coat- / Coët-**
Bois, forêt (du breton *koad*).
Exemples : Coëtlogon, Coëtmieux, Coat-Méal.

**Bod-**
Demeure, résidence (du breton *bod*).
Exemples : Bodilis (Bodiliz), Botsorhel.

**Moustoir- / Mouster-**
Monastère, moutier.
Exemples : Le Moustoir, Moustoir-Ac, Moustoir-Remungol.

**Pont- / Pond-**
Pont.
Exemples : Pontivy (Pondi), Pont-l'Abbé (Pont-'n-Abad), Pont-Croix.

**Aber-**
Aber, estuaire.
Exemples : l'aber Wrac'h, l'aber Benoît, l'aber Ildut (les trois abers du Léon).

**Menez- / Ménez-**
Mont, montagne (du breton *menez*).
Exemples : Ménez-Hom, Ménez-Bré, Ménez-Meur (des sommets).

**Beg-**
Pointe, bec (du breton *beg*).
Exemples : Beg-Meil, Beg-Léguer.

## En fin de nom

**-kemper / Kemper**
Confluent.
Exemples : Quimper (Kemper), Quimperlé (Kemperle, « le confluent de l'Ellé »), Quemper-Guézennec.

**-kastell / -gastel / -castel**
Château (du latin *castellum*).
Exemples : Plougastel-Daoulas, Trégastel, Saint-Pol-de-Léon (Kastell-Paol).

**-iliz (-ilis, -illis)**
Église (du breton *iliz*).
Exemples : Lannilis (Lanniliz), Bodilis (Bodiliz).

**-mael**
Prince, chef (du vieux breton *mael* ; sens probable).
Exemples : Ploërmel (Ploermael), Maël-Carhaix, Maël-Pestivien.

**-meur**
Grand (du breton *meur*).
Exemples : Plomeur (Ploveur), Ploemeur (Plañvour).

**-nevez**
Neuf, nouveau (du breton *nevez*).
Exemples : Plounévez-Lochrist, Plonévez-du-Faou, Plounevez-Moëdec.

**-marc'h**
Cheval (du breton *marc'h*).
Exemples : Penmarc'h (« le bout du cheval »), Kermarc'h.

**-ac / -ec / -oc (formes françaises -é, -y)**
« Domaine de (un nom de personne) », suffixe gallo-romain *-acum*.
Exemples : Carnac (Karnag), Bourbriac (Boulvriag), Lanvéoc (Lañveog).

**-ac'h / -ec'h**
Variante bretonne du même suffixe domanial ; on la retrouve surtout dans les formes en langue bretonne.
Exemples : Logunec'h (Locminé), Penmarc'h.

**-venez / -enez**
Île (du breton *enez*).
Exemples : Douarnenez (probablement « la terre de l'île », *douar an enez*).

**an / ar**
L'article défini breton (« le, la, les »). Il soude souvent deux mots.
Exemples : An Oriant (Lorient, « l'Orient »), An Alre (Auray).

**bro / Breizh**
Pays (du breton *bro*), et Bretagne (Breizh).
Exemples : Penn-ar-Bed (le Finistère, « le bout du monde »), Breizh.
